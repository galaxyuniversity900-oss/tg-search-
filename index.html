Install the Telegram search engine on Android / Termux

This public website is the interface. Real Telegram search requires the local Python bridge running on your phone; GitHub Pages cannot run that backend. Download the files below, then follow the setup guide.

  1. Install Pydroid 3 (Android) or Termux, then add the telethon package.
  2. Save tg_atlas.py below and run it. It prints a link starting with http://127.0.0.1
  3. Paste that link in the connection box at the top and sign in with your phone number and code.
