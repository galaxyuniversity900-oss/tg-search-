# TG-Atlas

واجهة بحث عن قنوات/مجموعات/بوتات تيليجرام، مقسّمة الآن كملفات مشروع عادية بدل ملف HTML واحد.

```
tg-atlas/
├── index.html          الصفحة
├── css/style.css        التنسيق
├── js/app.js             منطق الواجهة (JavaScript)
└── server/               برنامج بايثون الذي يتصل فعليًا بـ Telegram API
    ├── tg_atlas.py
    ├── setup_termux.sh
    ├── tg_atlas_config.json
    └── README.txt
```

## قبل ما ترفعه على GitHub Pages — نقطة مهمة جدًا

الصفحة عندها طريقتان للعمل، وفرق كبير بينهم بره Claude:

1. **وضع "Tele" (داخل Claude فقط)** — يستخدم كائن `mcp` اللي توفره بيئة Claude نفسها
   (`mcp.callTool`, `mcp.listTools`...). هذا الكائن **غير موجود إطلاقًا** في أي متصفح
   عادي أو على GitHub Pages. يعني بعد الرفع، وضع "Tele" لن يعمل أبدًا — مش مسألة إعداد
   ناقص، هو حرفيًا غير متاح خارج محادثة Claude.

2. **وضع "الجسر" (bridge / Telegram API الحقيقي)** — هو الوحيد اللي ممكن يشتغل خارج Claude،
   لكنه يحتاج:
   - تشغيل `server/tg_atlas.py` (برنامج بايثون كامل يستخدم مكتبة Telethon) على جهاز
     المستخدم نفسه أو سيرفر يملكه — **ليس على GitHub Pages**، لأن Pages يستضيف ملفات
     ثابتة (HTML/CSS/JS) فقط ولا يشغّل بايثون.
   - `api_id` و`api_hash` حقيقيين من [my.telegram.org](https://my.telegram.org)،
     وتسجيل دخول برقم الهاتف الحقيقي لصاحب الحساب.
   - بعد تشغيله، يطبع رابط محلي (`http://127.0.0.1:PORT/?t=...`) يتم لصقه داخل الصفحة
     لتعمل الصفحة فعليًا "live" ضد تيليجرام.

باختصار: **GitHub Pages يستضيف الواجهة فقط**. أي بحث فعلي في تيليجرام يحتاج السيرفر
المحلي شغّال على جهاز المستخدم بمفاتيحه الخاصة — هذا ليس قيدًا تقنيًا أقدر أحذفه بإعادة
الهيكلة، لأن Pages لا يُشغّل كود خادم بأي حال.

## النشر على GitHub Pages

```bash
git init
git add .
git commit -m "TG-Atlas"
git branch -M main
git remote add origin https://github.com/USERNAME/tg-atlas.git
git push -u origin main
```
ثم من إعدادات المستودع (Settings → Pages) اختر Branch: `main`, Folder: `/ (root)`.
الصفحة بعدها تكون على `https://USERNAME.github.io/tg-atlas/`.

## ملاحظة على خادم بايثون المحلي

`server/tg_atlas.py` يسجّل دخولك الحقيقي على تيليجرام ويبحث/يزحف عبر حسابك، ويتجاوز حد
الـ~100 نتيجة لكل بحث بتقسيم الاستعلام تلقائيًا، وله وضع "زحف" (snowball) يتبع التوصيات
والإشارات داخل المنشورات لاكتشاف قنوات جديدة تلقائيًا. هذا النوع من الأتمتة قد يخالف
شروط استخدام تيليجرام إذا استُخدم بكثافة، وتيليجرام قد يقيّد الحساب إن رأى نشاطًا غير
اعتيادي — الملف نفسه يحذّر من هذا وينصح بحساب ثانوي وتهدئة معدل الطلبات. هذا الجزء لم
أُضف إليه أي شيء جديد؛ هو نفس الكود الموجود أصلًا داخل ملفك المرفوع، فقط فصلته لملف
`.py` مستقل كما طلبت.
