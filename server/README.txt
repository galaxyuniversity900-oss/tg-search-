TG-Atlas — Termux quick start

1) Put tg_atlas.py and setup_termux.sh in the same folder.
2) Run: sh setup_termux.sh
3) Run: atlas
4) Open the local URL printed by the command.
5) Enter Telegram API ID/hash from https://my.telegram.org, then your phone number and the code Telegram sends. Enter your 2FA password only if requested.

The public GitHub Pages website is the user interface only. The Python bridge must run locally for live Telegram search.
Never upload tg_atlas_config.json, *.session, or tg_atlas.db.
